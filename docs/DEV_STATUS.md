## 2. 1対1向けの簡略化（原作と異なる箇所）

- 烏瞰図「全味方に迅速3」→ 使用者本人のみ。
- 盾持ち兵士のパッシブ「混乱耐性3回復」→ 幕開始時に次の混乱閾値を3下げる。
- 昏がりのドロー条件「相手の混乱耐性が半分以下」→ 相手のHPが最大HPの半分以下。
- 振動爆発 → 次の混乱閾値を「振動威力×倍率」HP分上げる。原作の正確な換算式は未確認。
- 混乱閾値の初期値 → 旧データの「混乱耐性 / HP」比から計算。
- 士気低下は原作では確率発生だが、確率が未確認のため -30 以下なら毎幕発生。
- パニックタイプの「味方への効果」は1対1では省略。自殺の死亡は敗北扱い。
- 徘徊のパニックは独自効果「幕開始時に手札をランダムに1枚失う」（原作の逃走は不採用）。
- ドンキE.G.Oパッシブ: 嫉妬スキルの与ダメージ+10%、嫉妬共鳴発生時はさらに+5%。
- 過ぎし日: 「4以上の共鳴」は憂鬱共鳴の発生で代用、味方回復は自分のみ（侵蝕は省略）、攻撃の重さは省略。
- 他人の鎖のパッシブ「3つ以上のスキルに指定」→「2つ以上」（相手の速度ダイスが最大2つのため）。
- 呼吸: 以前は「威力=クリティカル率%、1.5倍」だったが、LCBのPoiseに合わせ「威力×5%、1.2倍」に変更（剣契のクリティカル追加倍率前提）。
- 剣契: 原作の味方への呼吸付与は自分に置き換え。挑発値・攻撃の重さは省略。骨断の「単一対象+100%」は1対1で常時発動になるため省略。
- 充電: LoRは上限10（W社のスーツで20）のリソース、LCBは幕終了時に1減少。両方を採用。
- W社: 「敵撃破時」の効果は1対1では決着と同時になるため、マッチ勝利時などに置き換え。破裂は不採用（脆弱に置き換え）。
- LoR WARP整理班のページ（過充電・次元の狭間・波動・遡行）は効果のみLoR準拠（ユーザー提供）。ダイスはこのゲーム向けに設定。
- LCBとLoRで同名の「エネルギー循環」「跳躍」は1枚に統合（LoRの効果を追加）。
- 黒獣-卯: サポートパッシブ不採用。「10以上の速度」は速度ダイスの値で判定（脚力【卯】の迅速5で到達）。瞬歩・刺殺に光回復・ドローを追加（このゲーム独自）。
- キムサッガ・剣契師範由来のページ（抜剣・刺法・肉斬・殺主・骨断）はLCB 剣契師範ムルソーの基礎/コイン威力をそのまま使用（2026-10-12）。
- 着影揮刀: wiki個別ページが取得できず攻略サイトの記載を参照。「味方」は自分のみとして扱う。恨の宿った鞘の「本国剣 - 真詮伝授」付与は自分を除く剣契の味方が対象のため1対1では発動しない。追慕パッシブ最大効果は「自分のスキルで得る/与える状態の威力・回数+2」として実装。
- 四本目のマッチの火・一生シチュー（2026-10-12, wiki Tier V）: 「全ての対象/主対象」は相手1人。「配置順で味方に付与」は本人のみ（この幕と次の幕）。罪悪資源の上限は99に引き上げ（2026-10-12、以前は10）。資源量比例の効果・暴食のるつぼの「色欲20以上」は原作どおり。共鳴数はこのゲームの共鳴（2以上で発生、最大2）。攻撃レベル+3・攻撃の重さ・オーバークロックは省略。破壊不能コインの「敗北後コイン威力1固定」は既存E.G.Oと同じく省略。「攻撃前」の最終威力はマッチに影響しない（原作準拠）。
- 「X火傷を与える」は火傷威力として扱う（wikiに威力/回数の区別がないため、LCBの表記慣習に従った）。四本目のマッチの火は「的中で火傷4」と「表で的中で火傷6」が両方発動する（表なら計10）。
- 日本語名（ユーザー確認済み）: パッシブ「火の粉」（Ember）、「暴食のるつぼ」（Cauldron of Gorging）、状態「燃え上がる」（Blazing）。
- 一生シチューはユーザー提供の解析Vテキストに合わせた（2026-10-12）: 的中時は火傷・出血の「回数」+3（侵蝕+4）。攻撃前の色欲威力増加（侵蝕は色欲ダメージ量増加も）は「色欲資源6つにつき味方1名へ次のターン」→ 1対1では色欲資源6以上なら自分に次の幕のみ（この幕には付かない）。「火傷と出血の合計」は両者の威力の合計として扱う。暴食のるつぼの与ダメージは色欲属性の基本「攻撃」スキルのみ。
- 破壊不能コインでマッチ敗北後に攻撃するときも、E.G.Oの攻撃前・攻撃終了時の処理を行うようにした（2026-10-12）。
- 的中時の「相手に与える」状態は、実際に的中した対象へ付与する（敵味方識別不可で自分を攻撃した場合は自分）。以前は常に相手に付与されていた。
- リウ協会（2026-10-12）: 名前は仮訳（ユーザー確認待ち）。HPはLCB 257 → 80。ピンポイント電撃戦4枚目の固定ダメージ上限 30 → 10（HP規模に合わせ縮小）。焔手刀-燃焼の「火傷が無い/少ない2体に火傷3」は相手への火傷3に置き換え。熱き情熱の「憤怒共鳴の高い味方へ」は本人。LoRの感情レベル条件・熱烈な感情の反撃ダイスは省略し、熱烈な感情はコスト4→3。天を裂く烈火は春・シャオのパッシブ（LoR）。LoRの火傷（幕開始時ダメージ・1/3減少）ではなくLCB方式の火傷を使う。
- 20区ユロージヴィ・低い鳴き声（2026-10-14）: 名前は仮訳（「低い鳴き声」= Cavernous Wailing と判断）。HP 214 → 75、「待って?!」のバリア上限 13 → 5。自分に貯める振動は回数で判定。原作は味方が相手に振動回数を供給するため、1対1では「自分の振動回数+N」で相手にも振動回数+Nを与える（独自の追加）。振幅もつれ／振幅変換は「相手の振動を振動 - 残響にする」に統一（重ね合わせは省略）。低い鳴き声の「最も高い共鳴4以上」は「共鳴が発生」。振動溶接変形杖の怠惰6保有条件は省略（常時有効）。サポートパッシブ不採用。
- 振動: 幕終了時に回数-1（LCB準拠。以前は説明文だけで処理がなかった）。振動爆発は回数-1する（原作では「爆発後に回数-1」と書かれたスキルのみだが、既存の処理に合わせた）。
- 混乱閾値は人格につき1つ（複数閾値は未実装）。一度混乱すると振動爆発の効果がなくなるため、振動は原作より弱い。
- 麻痺は回数=0にするコインの枚数（valueFromCount）。
- 出血・沈潜等は、威力のみ付与されたら回数1、回数のみなら威力1（原作準拠）。
